# 원티드 AI Championship 2026 출품 준비

확인 기준: 2026-08-25

공식 안내: https://event.wanted.co.kr/ai-championship/2026

## 출품 가능성

구독청소는 자유 주제 과제의 조건인 “AI를 활용해 실제 문제를 해결하거나 새로운 가치를 만드는 프로젝트”에 맞습니다. 기존에 직접 만든 프로젝트의 제출도 허용되므로, 현재 MVP를 출품용 버전으로 확장해 제출할 수 있습니다.

현재 서비스는 여러 카드와 결제 알림에 흩어진 자동결제를 AI로 정리해주는 개인정보 보호형 구독 관리 도구입니다. 결제내역을 붙여넣기만 하면 결제처를 통합하고, 구독 가능성과 해지 우선순위, 월·1년 예상 절약액을 확인할 수 있습니다. 금융기관 연동이나 서버 저장을 기본으로 사용하지 않아 개인정보 부담을 낮춘 것이 특징입니다.

## 제출 폼에 붙여넣을 내용

### 제목

결제내역을 붙여넣으면 AI가 구독 후보와 다음 행동을 알려주는 구독청소

### 해결하고자 한 문제

카드·간편결제·앱스토어에 흩어진 반복 결제를 놓쳐 매달 새는 돈을 발견하기 어렵습니다. 구독청소는 사용자가 결제내역을 한 번 붙여넣는 것만으로 반복 결제를 찾고, 유지·해지예정·모름으로 정리하도록 돕습니다.

### AI 활용 방식 및 결과

구독청소는 브라우저에서 결제 원문을 날짜·결제처·금액·주기·신뢰도 같은 구조화된 요약값으로 먼저 정리합니다. 이 과정에서 `APPLE.COM/BILL`, `애플`, `Apple 결제`처럼 다른 표현을 하나의 결제처로 통합하고, OTT·쇼핑·AI 도구·클라우드·음악·게임으로 자동 분류합니다. 사용자가 `분석` 버튼을 누를 때만 모든 후보의 최소 요약값을 Vercel 서버 함수가 Google Gemini API에 한 번에 전달하고, Gemini가 후보별 반복 결제 판단 근거·해지 우선순위·월·1년 지출 영향·다음 확인 행동을 JSON 형식으로 생성합니다. 원문 결제내역과 카드번호·계좌번호·전화번호·이메일·고객 식별정보는 AI 요청에 포함하지 않으며, API 키는 브라우저에 노출하지 않고 `GEMINI_API_KEY` 서버 환경변수로 보호합니다. AI 일괄 분석은 하루 7회로 제한하고 사용량을 화면에 표시하며, 키 없음·권한 오류·사용량 초과·시간 초과·서버 오류·JSON 파싱 실패 때는 `AI 분석을 사용할 수 없어 기본 분석 결과를 표시합니다.`라는 안내와 함께 후보별 로컬 설명으로 대체됩니다.

### 서비스 링크

https://subscription-cleaning.vercel.app/

### 주요 AI 도구 및 활용 방식

- Google Gemini API: 정규화된 최소 결제 요약값을 바탕으로 구조화된 후보 설명 생성
- ChatGPT/Codex: 제품 구조 설계, 프롬프트 작성, 코드 구현·테스트 보조
- Vercel: API 키를 보호하는 서버 함수와 서비스 배포

실행 중 AI는 Google Gemini API이며, 개발 보조에 ChatGPT/Codex를 사용했습니다. 폼에서 선택할 기술 태그는 실제 사용한 항목만 선택합니다. 추천: `ChatGPT`, `Vercel`. Gemini API 태그가 별도로 보이면 함께 선택합니다.

## 시연 시나리오

### 1. 문제 제시

“넷플릭스, 쿠팡와우, 애플, AI 도구를 쓰다 보면 매달 결제되지만 실제로 계속 쓰는지 놓치기 쉽습니다.”

### 2. 입력

홈 화면에서 `샘플`을 누르거나 카드 승인 문자 14건을 붙여넣고 `분석`을 누릅니다. 원문은 현재 브라우저에서만 파싱됩니다.

### 3. 결과

`Netflix`, `쿠팡와우`, `Apple`, `OpenAI ChatGPT`, `Adobe Creative Cloud` 후보가 나타나고, 결제처가 통합·분류됩니다. 월 예상 자동결제 금액과 각 결제의 반복 주기·신뢰도·다음 예상일·1년 예상액이 표시됩니다.

### 4. AI 일괄 분석

입력 영역의 `분석` 버튼을 누릅니다. 한 번의 요청으로 모든 후보에 대한 Google Gemini JSON 응답을 만들고, 각 카드 아래에 “최근 3개월 월간 반복 결제”, “월 17,000원 영향”, “다음 결제 전 실제 이용 여부 확인” 형태로 표시합니다. 시연 환경에서 Gemini 키가 없거나 API 오류가 나면 동일한 구조의 후보별 로컬 자동 설명으로 전환됩니다.

### 5. 행동으로 연결

상태를 `해지예정`으로 바꾸면 해지 우선순위와 월·1년 절약액, 절약 목표 진행률이 즉시 갱신됩니다. 사용자는 분석 결과를 보는 데서 끝나지 않고 다음 행동까지 정할 수 있습니다.

### 6. 신뢰·확장성 강조

카드번호나 결제 원문을 서버에 저장하지 않는 구조를 보여주고, 향후 OCR·CSV 업로드·해지 경로 안내·결제 전 리마인드로 확장할 수 있음을 설명합니다.

## 발표 핵심 한 문장

구독청소는 흩어진 결제 흔적을 반복결제 후보로 바꾸고, AI가 그 후보의 의미와 다음 행동을 설명해 사용자가 새는 돈을 직접 줄이게 하는 개인정보 최소화형 소비 점검 도구입니다.

## 발표자료 구성

1. 문제: 반복 결제는 여러 서비스와 카드에 흩어져 있다.
2. 해결: 붙여넣기 한 번으로 결제처 통합·분류·후보·금액·주기를 정리한다.
3. 시연: 14건 입력에서 5개 후보와 월·1년 예상액을 확인한다.
4. AI: 원문이 아닌 요약값만 보내 후보 설명과 해지 우선순위를 생성한다.
5. 신뢰: 로컬 우선 분석, 민감정보 제거, 서버 키 보호, 연결 실패 시 대체 설명.
6. 행동: 유지·해지예정·모름 기록을 반영해 해지 우선순위와 절약액을 제안한다.
7. 마무리: 사용자가 오늘 바로 하나의 구독을 점검하고 행동하게 만든다.
